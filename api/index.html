API JavaScript

Inisialisasi otomatis

Memuat croot.min.js sebagai module sudah cukup: setiap [data-croot] di halaman diinisialisasi saat DOM siap. Instance-nya tersimpan di properti root.croot.

<script type="module" src="https://cdn.jsdelivr.net/gh/crootss/crootss@v0.3.0/croot.min.js"></script>

Inisialisasi manual

Untuk mengatur opsi atau memakai API, beri root data-croot="manual" lalu impor croot dari file JS-mu sendiri.

import { croot } from 'https://cdn.jsdelivr.net/gh/crootss/crootss@v0.3.0/croot.min.js';

const deck = croot('#deck', { fit: 0.9, pullback: 1, hash: true, keyboard: true, touch: true });

deck.next();
deck.goto('ruang');
deck.root.addEventListener('croot:enter', (e) => {
  console.log('masuk', e.target.id, 'langkah', e.detail.index);
});

croot() idempoten: memanggilnya lagi pada root yang sudah aktif mengembalikan instance yang sama. Bila root tidak ditemukan atau tidak berisi .croot-stage, ia melempar Error.

croot(root, options)

ParameterKeterangan
rootElemen atau selector. Bila kosong, memakai [data-croot] pertama.
options.fitPorsi layar yang diisi node aktif. Default 0.9. Atribut data-croot-fit menimpa nilai ini.
options.pullbackKekuatan kamera mundur di tengah perpindahan. Default 1, 0 = mati. Atribut data-croot-pullback menimpa nilai ini.
options.hashSinkronkan node aktif dengan #/<id> di URL. Default true.
options.keyboardAktifkan navigasi keyboard. Default true.
options.touchAktifkan swipe. Default true.

Instance

AnggotaKeterangan
next(), prev()Maju atau mundur satu langkah. Dari overview, keduanya kembali ke node terakhir.
goto(target)Terbang ke node. target berupa index langkah (angka), id (string, boleh diawali # atau #/), atau elemen node. Mengembalikan false bila target tidak valid.
overview(force)Tanpa argumen: buka/tutup overview. true / false: paksa buka atau tutup.
destroy()Lepas semua listener, hapus class dan transform. Halaman kembali ke mode dokumen.
currentNode aktif (elemen).
indexIndex langkah terakhir. Tidak berubah saat node tanpa step diklik.
isOverviewtrue saat overview terbuka.
stepsArray node berurutan sesuai data-croot-step.
rootElemen root.

Event

Semua event adalah CustomEvent yang menggelembung (bubbles), jadi cukup didengarkan di root.

EventDikirim didetail
croot:enternode yang baru aktif{ previous, index }
croot:leavenode yang ditinggalkan{ next }
croot:overviewroot{ current }

Contoh: bilah navigasi

HTML, CSS, dan JS di file terpisah. Tombol tanpa onclick; satu listener di bilah menangani semuanya.

<nav class="hud" aria-label="Navigasi presentasi">
  <button class="hud-btn" data-act="prev" aria-label="Sebelumnya">←</button>
  <span class="hud-pos" aria-hidden="true"></span>
  <button class="hud-btn" data-act="next" aria-label="Berikutnya">→</button>
</nav>
import { croot } from 'https://cdn.jsdelivr.net/gh/crootss/crootss@v0.3.0/croot.min.js';

const deck = croot('#deck');
const pos = document.querySelector('.hud-pos');

document.querySelector('.hud').addEventListener('click', (e) => {
  const act = e.target.closest('[data-act]')?.dataset.act;
  if (act === 'prev') deck.prev();
  if (act === 'next') deck.next();
});

function update() {
  pos.textContent = deck.isOverview ? 'Overview' : `${deck.index + 1} / ${deck.steps.length}`;
}
deck.root.addEventListener('croot:enter', update);
deck.root.addEventListener('croot:overview', update);
update();

// Sembunyikan bilah saat penonton diam (class .hud-idle dari tema)
const hud = document.querySelector('.hud');
let idleTimer = 0;
function wakeHud() {
  hud.classList.remove('hud-idle');
  clearTimeout(idleTimer);
  idleTimer = setTimeout(() => hud.classList.add('hud-idle'), 2500);
}
document.addEventListener('pointermove', wakeHud, { passive: true });
document.addEventListener('pointerdown', wakeHud, { passive: true });
wakeHud();

Utilitas

Modul juga mengekspor parseStep(value) ("2.10" → [2, 10]) dan compareStep(a, b) untuk mengurutkan langkah dengan aturan yang sama seperti crootss.
