Tombol diabaikan saat fokus ada di input, textarea, select, atau elemen contenteditable, serta bila ditekan bersama Ctrl, Alt, atau Meta.

Klik dan sentuh

  • Klik node mana pun untuk terbang ke sana. Urutan linier ikut tersinkron bila node itu punya step.
  • Link, tombol, dan form di dalam node tidak dibajak; klik pada elemen itu berjalan normal.
  • data-croot-target pada tombol atau link membuat kamera terbang ke selector tujuan.
  • Swipe minimal 50px: ke kiri atau atas untuk maju, ke kanan atau bawah untuk mundur.

Overview

Overview memundurkan kamera sampai seluruh node muat di layar (dihitung dari bounding box semua node). Klik node mana pun untuk masuk lagi, atau tekan Esc / → untuk kembali ke node terakhir.

Alamat URL

Setiap node aktif menulis #/<id> ke URL (tanpa menambah riwayat browser), dan overview menulis #/overview. Membuka URL dengan hash itu langsung menuju node yang bersangkutan, jadi slide tertentu bisa dibagikan sebagai link. Matikan dengan opsi hash: false.

Kamera 3D

Saat berpindah ke node yang jauh di layar, kamera mundur sejenak lalu maju lagi, sehingga penonton melihat ruang di antaranya. Besarnya mundur bergantung pada jarak; perpindahan dekat tidak memakai efek ini. Atur dengan data-croot-pullback pada root (0 = mati, 2 = lebih dramatis).

Supaya efek 3D terasa, sebar slide di ruang: beda x, y, dan z, dengan sedikit rotasi. Slide yang semuanya sebidang akan terasa seperti geser datar.

Aksesibilitas

  • Node aktif mendapat aria-current="step".
  • Setiap perpindahan diumumkan ke pembaca layar lewat region aria-live: posisi dan heading pertama node, misalnya "3 / 12: Pasang". Pakai aria-label pada node untuk teks lain.
  • prefers-reduced-motion: reduce dihormati: kamera berpindah seketika.
  • Konten tetap berupa teks HTML biasa sehingga bisa dipilih, disalin, diterjemahkan, dan diperbesar.
