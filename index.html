Dokumentasi crootss

crootss adalah engine presentasi spatial 3D berbasis CSS 3D transforms. Slide ditulis sebagai HTML biasa, diletakkan di ruang 3D lewat atribut, lalu kamera terbang di antaranya.

Isinya dua file: crootss.css (layout dan animasi) dan croot.js (kamera dan navigasi, ES module). Tanpa dependency, ±9 KB minified, tanpa build. Karena konten tetap berupa teks di DOM, presentasimu terindeks mesin pencari dan tetap terbaca sebagai dokumen biasa saat JavaScript mati.

Mulai cepat

Simpan sebagai index.html, jalankan server lokal di foldernya (lihat Menjalankan di komputer), lalu buka di browser.

<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Presentasi pertamaku</title>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/crootss/crootss@v0.3.0/crootss.min.css">
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/crootss/themes@v0.2.0/poster.min.css">
  <script type="module" src="https://cdn.jsdelivr.net/gh/crootss/crootss@v0.3.0/croot.min.js"></script>
</head>
<body>
  <main class="croot-viewport" data-croot>
    <div class="croot-stage">
      <section class="croot-node slide t-1 cover" id="halo" data-croot-step="1">
        <h1>Halo.</h1>
        <p class="lead">Presentasi pertamaku dengan crootss.</p>
      </section>
      <section class="croot-node slide t-3 center" id="kedua" data-croot-step="2"
               data-croot-x="2000" data-croot-z="-600" data-croot-ry="-30">
        <h2>Slide kedua, <span class="hl">di ruang 3D.</span></h2>
      </section>
    </div>
  </main>
</body>
</html>

Tekan → atau Spasi untuk maju, Esc untuk melihat seluruh ruang. Class slide, t-1, cover, dan seterusnya berasal dari tema. Tanpa tema, crootss tetap jalan; kamu yang mengatur gayanya.

Selalu pin versi CDN (@vX.Y.Z), jangan @latest. Versi terbaru ada di Releases library dan Releases tema.

Cara kerja

  1. Setiap .croot-node diberi posisi, rotasi, dan skala di ruang 3D lewat atribut data-croot-*.
  2. Saat node aktif berganti, croot.js menghitung matriks dunia node itu lalu memasang inversnya ke .croot-stage. Seluruh dunia bergerak sehingga node aktif tepat menghadap layar. Itulah "kamera".
  3. Perpindahan dianimasikan oleh transisi CSS. Untuk lompatan jauh, kamera mundur sejenak lalu maju lagi supaya ruang di sekitarnya terlihat.

Mode 3D hanya aktif setelah croot.js memberi class croot-ready pada root. Sebelum itu, atau tanpa JavaScript, semua node tampil berurutan sebagai halaman biasa.

Isi dokumentasi

  • Markup dan atribut: struktur, posisi, rotasi, urutan, node bersarang.
  • Navigasi: keyboard, klik, swipe, overview, URL, aksesibilitas.
  • API JavaScript: croot(), opsi, method, event.
  • Kustomisasi CSS: variabel, class status, tips 3D.
  • Tema: poster, gelap, minimal; class dan token; membuat tema.
  • Menjalankan di komputer: Windows, macOS, Linux.

Contoh nyata: halaman crootss.if.co.id sendiri adalah presentasi crootss (lihat HTML-nya).
