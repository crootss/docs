Big picture dan diagram

Presentasi crootss dimulai dari gambaran besar, lalu kamera zoom ke tiap blok untuk detailnya. Penonton selalu tahu posisinya di dalam cerita.

Konvensi

  1. Satu big picture. Buat satu node yang memuat seluruh struktur presentasi sebagai diagram, dan daftarkan dengan data-croot-overview="#id" pada root.
  2. Tampilkan di awal. Big picture menjadi langkah pertama, atau langkah kedua setelah sampul.
  3. Blok, lalu detail. Setiap cabang diagram adalah blok (node); detailnya adalah node anak di dalam blok atau blok kecil di sebelahnya. Urutan langkah: blok → detailnya → blok berikutnya.
  4. Satu bidang. Blok berada di bidang yang sama dengan big picture supaya overview terbaca sebagai satu gambar. Gunakan z dan rotasi seperlunya, untuk penekanan.
  5. Kembali ke big picture. Esc selalu membuka big picture, dan → setelah langkah terakhir kembali ke sana (otomatis bila data-croot-overview diisi).

Contoh nyata: crootss.if.co.id disusun sebagai concept map. Tekan Esc di sana untuk melihat petanya.

Atribut big picture

<main class="croot-viewport" data-croot data-croot-overview="#peta">
  <div class="croot-stage">
    <!-- Big picture: satu node yang memuat seluruh struktur -->
    <div class="croot-node peta" id="peta" data-croot-step="1">
      <h2>Rencana rilis</h2>
      <svg class="dg" viewBox="-1200 -700 2400 1400" aria-hidden="true">
        <path class="dg-edge dotted a-flow" d="M0 0 L-800 -350"/>
        <path class="dg-edge dotted a-flow" d="M0 0 L800 -350"/>
        <path class="dg-edge dotted a-flow" d="M0 0 L0 450"/>
        <g class="dg-label" transform="translate(-400 -175)"><rect x="-90" y="-22" width="180" height="44" rx="22"/><text>dibangun</text></g>
      </svg>
    </div>
    <!-- Blok: tiap cabang, satu bidang dengan peta -->
    <section class="croot-node slide" id="pusat" data-croot-step="2">…</section>
    <section class="croot-node slide" id="produk" data-croot-step="3"
             data-croot-x="-800" data-croot-y="-350" data-croot-scale="0.3">…</section>
    <!-- Detail: node anak di dalam blok, zoom satu per satu -->
  </div>
</main>

Tanpa data-croot-overview, overview memundurkan kamera sampai semua node muat. Dengan atribut itu, overview membingkai node big picture, sehingga diagram, judul, dan garis penghubungnya tampil utuh. Node big picture biasa dibuat besar (mis. 10000px) dan ditempatkan di belakang blok (--croot-z negatif) supaya bisa diklik untuk kembali ke peta.

Kelas diagram

Semua kelas berasal dari tema, murni CSS, dan memakai warna tema.

KelasFungsi
dgPada <svg>: wadah diagram. Teks di dalamnya memakai font tema.
dg-edgeGaris/panah (<path>). Varian dotted dan dashed; jarak titik lewat --dg-gap.
dg-boxKotak atau lingkaran berwarna permukaan dengan garis tepi.
dg-labelPada <g> berisi <rect> dan <text>: label pil untuk garis.
dg-headIsi <marker> untuk mata panah.
bmc, bmc-kp … bmc-rvBusiness Model Canvas: kp mitra, ka aktivitas, kr sumber daya, vp nilai, cr relasi, ch kanal, cs pelanggan, co biaya, rv pendapatan. Posisi dan ukuran sudah diatur, desktop dan ponsel.
flow, timelinePada <ol>: alur dengan panah, atau garis waktu dengan titik.
 
<section class="croot-node slide t-7 bmc" id="kanvas" data-croot-step="4">
  <p class="eyebrow"><b>03</b> Model bisnis</p>
  <h2>Sembilan blok, klik untuk zoom.</h2>
  <div class="croot-node bmc-vp" data-croot-step="4.1"><h3>Nilai</h3><p>…</p></div>
  <div class="croot-node bmc-cs" data-croot-step="4.2"><h3>Pelanggan</h3><p>…</p></div>
  <!-- bmc-kp, bmc-ka, bmc-kr, bmc-cr, bmc-ch, bmc-co, bmc-rv -->
</section>

Animasi

Kelas animasi hanya berjalan saat node yang memuatnya aktif (dan a-flow juga saat overview), lalu mati otomatis bila sistem meminta "kurangi gerakan". Isi slide tema juga masuk bergiliran tanpa kelas tambahan.

KelasGerak
a-drawGaris SVG tergambar dari awal ke akhir. Beri pathLength="1" pada <path>.
a-flowTitik-titik .dg-edge.dotted mengalir sepanjang garis.
a-inMasuk memudar; urutan lewat --i (0, 1, 2, …) di CSS-mu.
a-float, a-spin, a-pulse, a-blinkMelayang, berputar, berdenyut, berkedip.

Konvensinya tetap ringan: tidak ada JavaScript tambahan, tidak ada library diagram. Diagram adalah HTML dan SVG biasa yang terbaca mesin pencari dan tampil sebagai dokumen saat JavaScript mati.
