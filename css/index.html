Kustomisasi CSS

Variabel

Atur di root, atau di selector yang lebih spesifik untuk satu presentasi.

.croot-viewport {
  --croot-perspective: 1000px; /* makin kecil, efek 3D makin kuat */
  --croot-speed: 1s;           /* durasi perpindahan kamera */
  --croot-ease: cubic-bezier(0.65, 0, 0.35, 1);
  --croot-node-width: 960px;   /* lebar default setiap node */
  --croot-dim: 0.35;           /* opacity node yang tidak aktif */
}

Tulis gaya mode 3D di bawah .croot-ready supaya mode dokumen (tanpa JS) tetap rapi:

.croot-ready .croot-node { height: 540px; }
.croot-viewport:not(.croot-ready) .croot-node { margin-bottom: 4rem; }

Ukuran node

Lebar node diambil dari --croot-node-width; tinggi mengikuti konten kecuali kamu mengaturnya. Ukuran berbeda per node boleh, karena kamera menyesuaikan zoom dari ukuran node aktif (offsetWidth dan offsetHeight). Untuk slide yang selalu 16:9, beri lebar dan tinggi tetap, lalu ganti ke 9:16 di ponsel lewat media query.

Tips 3D

  • Jangan beri overflow: hidden pada node induk. Properti itu meratakan preserve-3d, sehingga anak yang punya z atau rotasi ikut gepeng. Aman di node daun.
  • Jangan beri opacity < 1 pada node induk, karena alasan yang sama. Peredupan bawaan crootss hanya berlaku untuk node daun.
  • Anak di atas induk yang dirotasi butuh z kecil (mis. --croot-z: 2) supaya tidak tertutup permukaan induk.
  • Jarak antar slide minimal kira-kira satu tinggi slide, supaya node tetangga tidak menutupi node aktif.
  • Teks tetap tajam saat zoom dalam: crootss hanya memasang will-change selama kamera bergerak, lalu browser merender ulang teks pada skala akhir.
