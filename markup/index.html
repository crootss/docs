Markup dan atribut

Struktur

Tiga lapis: root (.croot-viewport dengan atribut data-croot), dunia (.croot-stage), dan node (.croot-node).

<main class="croot-viewport" data-croot>
  <div class="croot-stage">
    <section class="croot-node" id="halo" data-croot-step="1">
      <h1>Halo</h1>
    </section>
    <section class="croot-node" id="ruang" data-croot-step="2"
             data-croot-x="1400" data-croot-rz="90">
      <h2>Slide berikutnya</h2>
    </section>
  </div>
</main>

Beri setiap node id: dipakai sebagai alamat URL (#/halo) dan oleh goto().

Atribut node

AtributFungsi
data-croot-stepUrutan navigasi linier (lihat Urutan langkah). Node tanpa step tidak masuk urutan, tetapi tetap bisa diklik.
data-croot-x, -y, -zPosisi pusat node dalam px. x ke kanan, y ke bawah, z mendekat ke penonton (negatif = menjauh).
data-croot-rx, -ry, -rzRotasi dalam derajat terhadap sumbu x, y, z. Urutan penerapan: x, lalu y, lalu z.
data-croot-scaleSkala node (default 1). Kamera otomatis menyesuaikan, jadi node 3 kali besar tetap memenuhi layar saat aktif.
data-croot-targetPada elemen apa pun di dalam root: saat diklik, kamera menuju node yang cocok dengan selector ini, misalnya data-croot-target="#halo".

Atribut root

AtributFungsi
data-crootMenandai root. croot.js menginisialisasinya otomatis.
data-croot="manual"Matikan inisialisasi otomatis; panggil croot() sendiri (lihat API).
data-croot-fitPorsi layar yang diisi node aktif, default 0.9.
data-croot-pullbackKekuatan efek kamera mundur di tengah perpindahan, default 1; 0 mematikannya.

Urutan langkah

data-croot-step dibandingkan per segmen titik, bukan sebagai angka desimal: 2 < 2.1 < 2.2 < 2.10 < 3. Jadi sub-langkah bisa ditambah tanpa menomori ulang. Urutan di HTML tidak berpengaruh.

Node bersarang

Node boleh berisi node lain. Koordinat anak relatif terhadap pusat induknya, jadi memindahkan induk ikut memindahkan anaknya. Ini cocok untuk "zoom ke detail": slide berisi beberapa kartu kecil, lalu kamera masuk ke tiap kartu.

<section class="croot-node" id="fitur" data-croot-step="3" data-croot-x="3000">
  <h2>Tiga fitur</h2>
  <div class="croot-node" id="cepat" data-croot-step="3.1"
       data-croot-x="-300" data-croot-y="150" data-croot-scale="0.25">…</div>
  <div class="croot-node" id="ringan" data-croot-step="3.2"
       data-croot-x="300" data-croot-y="150" data-croot-scale="0.25">…</div>
</section>

Node anak dengan scale kecil tampil sebagai kartu mini di dalam induk; saat aktif, kamera memperbesarnya sampai memenuhi layar. Jika induk dirotasi, beri anak sedikit z (misalnya data-croot-z="2") supaya tidak tergambar di belakang permukaan induk.

Posisi lewat CSS

Setiap atribut posisi punya padanan custom property: --croot-x, --croot-y, --croot-z, --croot-rx, --croot-ry, --croot-rz, --croot-scale (tanpa satuan). Atribut menang bila keduanya ada. Gunakan ini untuk tata letak yang berbeda di ponsel:

#cepat  { --croot-x: -300; --croot-y: 150; --croot-scale: .25; }
#ringan { --croot-x:  300; --croot-y: 150; --croot-scale: .25; }

@media (max-width: 640px) {
  #cepat  { --croot-x: 0; --croot-y: -40;  --croot-scale: .36; }
  #ringan { --croot-x: 0; --croot-y: 240;  --croot-scale: .36; }
}

Nilainya dibaca sekali saat inisialisasi dan tidak terwariskan ke node anak.

Tanpa JavaScript

Sebelum croot.js berjalan, atau bila JavaScript mati, root tidak punya class croot-ready dan semua node tampil berurutan sebagai dokumen biasa dengan lebar maksimal --croot-node-width. Tulis konten yang tetap masuk akal dibaca dari atas ke bawah: heading berurutan, teks asli (bukan gambar teks).
