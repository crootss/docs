Tema

Tema dari crootss/themes memberi slide 16:9 yang siap pakai. HTML-nya sama untuk semua tema, jadi berganti gaya cukup mengganti satu baris CSS.

TemaGayaCocok untuk
posterBlok warna penuh, grotesk tebal raksasa, stiker, tekstur kertasPeluncuran, kelas, pitch
gelapPanggung gelap, sorot lampu, neon lime/magenta, label monospaceTalk teknis, demo produk
minimalSerif editorial, ruang lega, garis rambut, aksen terakotaKuliah, riset, laporan

Coba ketiganya di landing page lewat tombol ◐.

Pakai

Muat tema setelah crootss.min.css. Font Google ikut dimuat otomatis.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/crootss/crootss@v0.3.0/crootss.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/crootss/themes@v0.3.0/poster.min.css">
<script type="module" src="https://cdn.jsdelivr.net/gh/crootss/crootss@v0.3.0/croot.min.js"></script>

Slide

<section class="croot-node slide t-3 split" id="pasang" data-croot-step="2"
         data-croot-x="2000" data-croot-ry="-35">
  <div>
    <p class="eyebrow"><b>01</b> Bab</p>
    <h2>Judul slide.</h2>
    <p class="sub">Penjelasan singkat.</p>
  </div>
  <div class="panel"><pre><code>…</code></pre></div>
</section>

Slide berukuran 1280×720 (16:9) di desktop dan 720×1280 (9:16) di layar ≤640px.

Class

ClassFungsi
slideWajib di setiap slide, bersama croot-node. Tambah tall untuk slide lebih tinggi (900px; 1800px di ponsel).
t-1 … t-8Warna permukaan slide atau kartu. Setiap tema punya 8 warna sendiri.
coverSampul: h1 raksasa dengan dekorasi.
splitDua kolom: teks dan panel atau kode.
centerSatu pernyataan besar di tengah.
colsKolom sejajar, 2 sampai 4 div.
eyebrowLabel bab; nomor di dalam <b>.
lead, sub, hlTeks pengantar besar, teks pendukung, sorotan warna aksen.
big, megaAngka atau kata raksasa.
panel, paperKotak kode atau kutipan; paper bergaya khas tiap tema.
btn, btn ghost, tag, sticker, keyTombol, label, stiker miring, tombol keyboard besar.
card, windowNode anak 1280×720 yang bisa di-zoom. window punya bilah jendela: <p class="chrome"><i></i><i></i><i></i></p>.
hud, hud-btn, hud-posBilah navigasi melayang (opsional, perlu JS sendiri; lihat contoh).
hud-idlePada hud: sembunyikan bilah saat penonton diam, seperti mode slideshow PowerPoint. Dipasang dan dilepas oleh JS-mu.

Kalau kamu mengatur sendiri ukuran teks raksasa, kalikan dengan --th-wide supaya tetap muat di tema berfont lebar: font-size: calc(240px * var(--th-wide));

Gerak

Supaya slide tidak terasa mati saat ditampilkan, tema menambahkan gerak hanya pada slide aktif:

  • Isi masuk bergiliran (memudar sambil naik) tepat sebelum kamera tiba. Pada split, teks masuk lebih dulu, lalu panel.
  • Gerak kecil terus-menerus: sticker bergoyang, key di cols "ditekan" bergantian, dan dekorasi khas tiap tema bergerak pelan (bentuk poster berputar/melayang, lampu REC gelap berkedip, ornamen minimal berputar).
  • Node anak (card, window) tidak dianimasikan karena posisinya diatur kamera.
  • Pengaturan sistem "kurangi gerakan" (prefers-reduced-motion) mematikan semuanya, dan tanpa JavaScript tidak ada animasi.

Animasi memakai properti translate, rotate, dan scale, bukan transform. Gunakan properti yang sama bila menambah animasi sendiri pada elemen yang sudah dirotasi tema. Keyframes bawaan (th-in, th-float, th-spin, th-wobble, th-blink) boleh dipakai ulang, misalnya untuk SVG animasi buatanmu:

/* Bergerak hanya saat slide-nya tampil */
.croot-active .logo-saya { animation: th-float 6s ease-in-out infinite; }

Token

Setiap tema hanya mengisi token --th-* di :root dan menambah dekorasi khasnya; layout bersama ada di base.css.

TokenFungsi
--th-page, --th-page-image, --th-fgLatar halaman, pola latar, warna teks.
--th-display, --th-text, --th-monoFont judul, teks, dan kode.
--th-display-weight, --th-display-tracking, --th-display-leadingKetebalan, jarak huruf, dan tinggi baris judul.
--th-widePengali ukuran teks raksasa untuk font lebar (default 1).
--th-s1 … --th-s8, --th-on-1 … --th-on-88 warna permukaan dan warna teks di atasnya (dipakai t-1 … t-8).
--th-panel, --th-on-panel, --th-panel-accentPanel kode.
--th-btn, --th-on-btn, --th-accentTombol dan warna aksen.
--th-radius, --th-shadow, --th-textureSudut, bayangan, dan tekstur slide.

Membuat tema baru

  1. Salin salah satu tema, misalnya minimal.css, dengan nama baru.
  2. Isi token --th-*. Untuk font display yang lebar, turunkan --th-wide.
  3. Tambahkan dekorasi lewat ::before / ::after pada .cover, .center, dan seterusnya.
  4. Cek di demo/ repo themes untuk desktop dan ponsel (±390px). Konten tidak boleh meluber di slide mana pun.

Nama class adalah API publik: tema boleh berbeda gaya, tetapi HTML yang sama harus tetap rapi di semua tema.
