Menjalankan di komputer

croot.js adalah ES module, dan browser tidak mau memuat module dari file:// (klik dua kali index.html). Jalankan server lokal di folder slide dengan salah satu cara di bawah, lalu buka http://localhost:8080/.

PowerShell

Bawaan Windows, tanpa instal apa pun. Buka PowerShell di folder slide, lalu jalankan:

irm https://crootss.if.co.id/serve.ps1 | iex

Browser terbuka otomatis. Tutup jendela (atau Ctrl+C) untuk berhenti.

Perintah ini mengunduh lalu menjalankan serve.ps1: server kecil (±50 baris, bisa kamu baca dulu) yang menyajikan folder saat ini dengan header Content-Type yang benar. Tanpa header itu browser menolak module ("Strict MIME type checking"). Juga jalan di PowerShell 7 (pwsh) di macOS dan Linux.

Python

Bawaan macOS dan Linux. Buka terminal di folder slide, lalu jalankan:

python3 -m http.server 8080

Di Windows yang sudah ada Python, ketik python. Tekan Ctrl+C untuk berhenti.

Kalau slide tidak bergerak

  • Alamat di browser diawali file://: jalankan server seperti di atas.
  • Console menampilkan "Strict MIME type checking": server tidak mengirim Content-Type untuk .js.
  • "Port 8080 sedang dipakai": tutup server lain yang masih jalan, lalu ulangi.
  • Halaman tampil sebagai dokumen biasa tanpa error: pastikan root punya atribut data-croot dan berisi .croot-stage.
